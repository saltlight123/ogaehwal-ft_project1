# 본인의 노트북에서 VS code를 열고 작업물을 커밋한 뒤 우리 조 깃허브(원격 저장소)로 push하는 방법입니다.
# 다음 명령어를 순서대로 git bash에 붙여 넣으면 됩니다.

$ git remote add origin https://github.com/saltlight123/ogaehwal-ft_project1.git
$ git remote -v
$ git push -u origin main

# 한 번 푸시해본 이후에는 그냥
    $ git push
만 해도 자동으로 수정사항이 원격 저장소에 연동됩니다.

# 다음은 반대로 깃허브에서 파일을 직접 수정하고서 로컬 저장소 쪽으로 수정사항을 반영하려고 할 경우입니다.
# 파일을 수정한 뒤, 본인 노트북의 VS code에서 git bash에
    $ git pull origin main
라고 붙여 넣으시면 됩니다.
