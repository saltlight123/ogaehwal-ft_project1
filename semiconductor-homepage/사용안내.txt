반도체 소개 홈페이지 사용 안내

1. ZIP 파일을 압축 해제한 뒤 index.html을 브라우저로 여세요.
2. HTML 파일과 style.css는 같은 폴더에 유지하세요. 별도 설치나 서버가 필요 없습니다.

파일 구성
index.html       메인: 요청한 순서대로 6개 주제 링크
definition.html  1. 반도체의 정의 (완성)
types.html       2. 반도체의 종류: 기능별, 재료별 (완성)
process.html     3. 반도체의 공정 (준비 중)
products.html    4. 제품과 회사 (제공한 조원 코드의 내용을 연결)
future.html      5. 미래의 반도체 양상 (준비 중)
game.html        퍼즐 맞추기 (준비 중, 게임 및 카운트 미구현)
style.css        모든 페이지의 공통 디자인과 모바일 대응

다른 조원 페이지 연결 방법
- 공정 담당 페이지를 process.html, 미래 담당 페이지를 future.html로 저장해 교체하세요.
- 게임을 완성한 뒤 game.html을 교체하세요.
- 파일명이 다르면 index.html의 해당 href를 실제 파일명으로 변경하세요.
- 새 페이지에서 공통 디자인을 사용할 때 head 안에 <link rel="stylesheet" href="style.css">를 넣으세요.
- 메인 복귀 링크는 <a href="index.html" class="back">← 메인으로 돌아가기</a>입니다.

내용 및 범위
- 정의/종류 페이지 하단에 조사에 사용한 공식 원문 출처를 연결했습니다.
- 제품/회사 페이지는 제공된 코드의 구조와 내용을 기반으로 공통 CSS를 사용하도록 옮겼습니다.
- HMB를 HBM으로 정정하고, 정의와 NAND/SSD 표현을 정확히 다듬었으며 순위 단정 표현을 완화했습니다.
- 공정/미래/게임은 다른 담당자의 작업과 겹치지 않도록 준비 중 페이지로 만들었습니다.
- 방문자 전체가 공유하는 완성 카운트는 아직 구현하지 않았습니다.
- 외부 글꼴/이미지/라이브러리에 의존하지 않아 본문은 오프라인에서도 표시됩니다. 참고자료 링크는 인터넷 연결이 필요합니다.
